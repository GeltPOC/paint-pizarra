# Paint Pizarra

Aplicación de pizarra estilo Paint con Next.js.

## Herramientas
- Lápiz, Borrador, Relleno (bote de pintura), Línea, Rectángulo, Círculo
- Selector de color y tamaño de pincel
- Limpiar lienzo y descargar como PNG

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
npm start
```
